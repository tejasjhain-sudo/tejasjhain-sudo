### ⚡ Executive Overview

I am **Tejas**, founder and lead software architect at **FlixStudios**. I engineer enterprise-grade Minecraft server cores, competitive duel suites, and low-latency packet engines designed for high-concurrency production networks (1.20 – 1.21+).

- ⚡ **Zero Main-Thread Latency**: Offloading heavy computations, database transactions, and packet filtering to asynchronous worker threads and Netty event loops (<0.02ms tick overhead).
- 🎯 **Sub-Tick Physics & Raycasting**: Mathematical 3D vector collision models, projectile trajectory simulation, and ping-compensated combat hit registration.
- 🛡️ **Packet-Level Interception**: Low-level Netty pipeline interception (PacketEvents / ProtocolLib) to enforce security and anti-escape containment before the game loop processes transactions.
- 🚀 **Folia & Paper 1.21+ Native**: Deeply versed in modern region schedulers, thread-safe asynchronous architectures, and HikariCP connection pooling.
